# 🧮 NeoCalc // Professional Grade Calculator

NeoCalc is a sleek, modern calculator designed for high-end portfolio showcases. It combines aesthetic Glassmorphism with advanced arithmetic functionality.
Live link : https://pro-calculator-tau.vercel.app/
## 🌟 Key Features
- **Modern UI**: Translucent glass effect with smooth CSS animations.
- **Dark Mode**: Toggle between light and dark themes with persistent state.
- **Full Arithmetic**: Support for basic operations, percentages, and square roots.
- **Calculation History**: View and clear your previous calculations (saved in LocalStorage).
- **Keyboard Support**: Fully functional via physical numeric keys and operators.
- **Error Handling**: Intelligent handling of "Division by Zero" and complex inputs.
- **Fully Responsive**: Optimized for mobile, tablet, and desktop screens.

## 🛠️ Built With
- **HTML5**: Semantic structure.
- **CSS3**: Custom variables, Flexbox/Grid, and Backdrop-filters.
- **Vanilla JavaScript**: Object-oriented logic and DOM manipulation.

## 🚀 Getting Started
1. Clone this repo.
2. Open `index.html` in any modern web browser.
3. Use the theme toggle on the top right for Dark Mode.
